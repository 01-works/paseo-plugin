# Supervision

작업 대화에서 `/supervise <목표>`로 감독을 시작하고, Command Center의 **내 감독으로 이동** 또는 `/my-supervisor`로 돌아갑니다. 원 대화는 맥락 출처로 유지하며, 지시·작업자 편입·정리는 감독이 먼저 사용자에게 묻습니다.

Paseo 앱·데몬 0.15.4 이상, 마크다운 기록·에스컬레이션 계약을 적용한 `yw-supervisor` 스킬과 Supervisor 프로필(`bootstrap-supervisor`)이 필요합니다. 프로필의 모델·모드·추론·native options를 사용하며 비어 있지 않은 legacy features는 거부합니다.

사용자 상태 폴더에 목표 기록을 남기고 코드 프로젝트 아래 local workspace와 감독 대화를 만듭니다. 원 대화 주소는 감독의 첫 프롬프트에 전달합니다. 라벨 연결에는 호스트의 Paseo CLI를 쓰며, 실패해도 첫 요청은 전달하고 경고를 남깁니다. 별도의 외부 네트워크 요청이나 비밀값 접근은 하지 않습니다.

명시적 감독 링크가 부모보다 우선합니다. 부모 체인에서는 감독 표식이 있는 대화만 열고 archive된 감독은 열지 않습니다. 부분 생성 오류와 링크 경고의 상세는 플러그인 로그에 남기며 toast에서 위치를 안내합니다.
