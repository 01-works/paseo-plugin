# Supervision

작업 대화에서 `/supervise <목표>`로 감독 대화를 시작하고, 작업자 대화에서 Command Center의 **내 감독으로 이동** 또는 `/my-supervisor`로 돌아갑니다. 원 대화는 계속 유지됩니다.

Paseo 앱·데몬 0.15.4 이상, 호스트의 `yw-supervisor` 스킬과 Supervisor 프로필(`bootstrap-supervisor`)이 필요합니다. 실제 감독 운영은 해당 스킬이 맡습니다. 명령은 기존 대화에서 사용합니다.

목표 원문과 원 대화 주소를 호스트의 사용자 상태 폴더에 기록하고, 코드 프로젝트 아래 local workspace와 감독 대화를 만듭니다. 프로필의 모델·모드·추론·features 설정을 그대로 적용합니다. 기존 대화의 라벨 연결에는 호스트의 Paseo CLI를 사용합니다. 별도의 외부 네트워크 요청이나 비밀값 접근은 하지 않습니다.

부모 체인에서 가장 가까운 감독을 우선합니다. archive된 감독은 안내하며 열지 않습니다. 다른 호스트의 부모는 호스트 ID와 함께 추적합니다. 생성 도중 실패하면 남은 리소스 경로와 ID를 표시하므로 이를 확인한 뒤 이어서 진행해야 합니다.
