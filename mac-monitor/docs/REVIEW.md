## 0.6.1 · 이력으로 관찰 대기 축소

2026-10-08 KST. [PLAN 18절](PLAN.md)의 이력 재사용을 관측의 신선도·대상 누락·CPU 기준점·
메타데이터 재검증·취소·모델 입력·UI 관점에서 자체 리뷰했다. 별도 에이전트는 만들지 않았다.

- 기존 이력의 연속/신선도 보장을 사용하되, 현재 목록/CPU가 준비된 경우만 관찰을 생략한다.
  검토할 대상 하나라도 이력이 부족하면 추가 관찰하며 준비 안 된 빈 목록을 정상 빈 결과로 해석하지 않는다.
- 이력/현재 CPU/요청 후 관찰을 모델과 화면에서 구분한다. 분당 평균의 최대를 순간 최대로 표시하지 않는다.
- 현재 실행 정보의 PID·시작 시각·부모·그룹·이름을 대조한다. 모델 대기 전 관찰을 해제하고,
  사용자 선택/확인과 종료 직전 최신 실행 정보·CPU·보호 검증을 유지한다.
- 헬퍼 바이너리·상시 수집 주기·보관 상한·모델·의존성은 그대로다. 새로운 상시 측정과 자동 AI 호출은 없다.

타입·113개 테스트·AST audit 0건·설치 번들의 Hermes 컴파일을 통과했다.
실제 로컬 RPC에서 약 240초 이력의 6개 대상을 검토했으며 **1.006초 뒤 Luna 검토로 전환**했고
전체는 **12.059초**였다. 약 11초는 모델 대기였으며 전체 검사까지 즉시 완료됐다고 쓰지 않는다.
정리 후보는 0개였고 종료 RPC를 호출하지 않았다. 결과 확인 뒤 검사를 취소했다.
실제 화면 제어는 시간 초과되어 이번 화면은 컴포넌트 테스트/번들 컴파일로 검증했다.

최종 검토에서 다음 문제를 수정하고 회귀로 확인했다.

- 네이티브 종료 응답의 IPC 구분 필드가 RPC에 섞이던 문제를 제거했다.
- 실행 정보 읽기 전에 관찰을 해제하면 최신 CPU 캐시가 없어지는 문제를 수정했다.
  읽기·CPU 대조까지 관찰을 유지하고 모델 호출 전에 해제한다.
- 완료 데이터를 반영하기 전에 폴링을 끄면 결과가 누락될 수 있어 데이터 반영 후 effect에서 끈다.
- 조회 응답을 기다리는 중 취소하면 뒤늦게 원본 정보가 저장될 수 있어 await 직후 취소 확인과 정리를 추가했다.
- `KERN_PROCARGS2`의 NUL을 전부 건너뛰는 대신 Apple의 32/64비트 정렬과 argc를 적용했다.
  빈 argv[0] 뒤 환경 영역을 읽지 않는 C 회귀를 실제 clang으로 검증했다.
- 조회 성공 형식이어도 인자/경로/CPU가 누락되면 읽기 실패로 처리한다. 모두 읽지 못한 결과는 오류다.
- 플러그인 정리는 검사를 먼저 취소한 뒤 헬퍼를 함께 닫는다. 대기 중인 실행 정보 응답을 해제해
  개별 IPC의 3초 시간 초과가 Paseo의 2초 종료 유예를 지연시키지 않게 했다.

실제 로컬 RPC/disable·enable을 검증했다. 직접 만든 자식만 SIGTERM으로 종료했다.

## 이전 0.2.1 · 자동 종료 경계

2026-10-06 KST. 기준은 승인된 PLAN과 후속 사용자 결정, 설치된 Paseo 0.10.2 타입이다.
계산/측정 비용, 네이티브 수명주기, 자동 종료 안전성, 오류 처리/로그, 클라이언트 상태와 실제 다크 화면을 검토했다.
리뷰에는 별도 AI 호출이나 서브에이전트를 사용하지 않았다.

### 발견과 수정

P1은 자동 조치의 허용/보호 조건 위반, P2는 결과 기록 누락이다. 네 건 모두 수정했다.

| 우선순위 | 결함과 재현 조건 | 수정 및 검증 |
|---|---|---|
| P1 | 자동 허용 요청이 PID·시작 시각·그룹만 전달했다. 확인 화면 이후 같은 식별자의 경로/이름이 바뀌면 서버가 새 값을 대신 허용했다. | 확인한 경로·이름을 필수로 전달한다. 네이티브 검증 전후에 모든 식별자를 대조하며 불일치는 거절한다. UI 요청 내용·경로/이름 변경·검증 중 변경·이전 요청 형식 거절 테스트 통과. |
| P1 | 네이티브 상위 경로 검사에서 터미널·일반 앱·시스템 보호가 제외됐다. 런처의 Codex/Paseo 조상을 제거한 `Terminal-test-parent` 아래 worker가 허용돼 재현됐다. | 대상과 조상에 같은 경로 보호를 적용한다. 검증용 Codex·Terminal·iTerm·Warp·일반 `.app` 부모의 자식을 허용/신호 단계에서 모두 차단했다. 독립 worker의 정상 허용·SIGTERM·종료 조회는 유지한다. |
| P1 | CLI 출력의 마지막 개행이 없으면 도구/실패/깨진 이벤트를 검사하지 않았다. 정상 결과 파일·종료 코드 0을 함께 주면 잘못된 출력을 받아들였다. | EOF의 남은 이벤트도 검사한다. 개행 없는 도구·실패·깨진 JSON/형식은 거절하고 정상 메시지는 허용한다. 알려진 시작 알림이 실패 이벤트 안에 있어도 실패를 우선한다. |
| P2 | 신호 후 10초 안에 플러그인이 종료되거나 조회 중 종료되면 최종 기록이 없었다. | 대기 중인 전송/조회는 마친다. 미조회 대상은 `unknown`, 시작한 조회는 실제 결과, 조회 예외는 `unknown`으로 한 번 기록한다. shutdown의 로그 실패도 cleanup을 막지 않으며 신호를 재전송하지 않는다. |

수정 전 새 단위 테스트에서 9개 실패를 확인했고, 네이티브 시험은 Terminal 자식 허용에서 실패했다.
검증용 프로세스만 생성·정리했으며 사용자 작업에는 허용이나 종료 신호를 보내지 않았다.
기존 자동 관리 설정/허용 저장 형식은 유지한다. 경로·이름이 없는 이전 클라이언트의 신규 허용은 거절되므로
업데이트 후 클라이언트 플러그인도 새 버전으로 로드해야 한다.

### 나머지 관점

- 계산: 메모리 합계·speculative 보정·Node 폴백, CPU 누적 차이·tick 역행·PID 시작 시각,
  null/0 구분을 기존 회귀 테스트와 대조했다. 공식을 변경할 근거가 없어 유지했다.
- 저부하: 단일 C 수집기, 2초 측정·캐시 RPC, 보이는 pill의 공유 읽기, 30초 앱 관심과
  30초 디스크 조회를 유지한다. 이번 변경은 허용/종료 경계에만 추가 검사를 넣는다.
  정상 압력에서는 자동 관리가 추가 스캔·AI 호출·파일 기록을 만들지 않는다.
- 종료 안전성: PID·시작 시각·경로·UID·조상 보호, 모델 결과 검증, 지속 압력/증가 추세,
  최신 측정/현재 CPU/실행 여유, 일회성 허용 소비, 예산·취소를 확인했다. SIGTERM 이후 재시도는 없다.
- 로그: 예정 기록 반영 실패 시 신호 차단, JSON lines 순서·0600·256 KiB 회전,
  전송과 실제 종료 구분, 조회 실패/플러그인 종료의 미확인 기록을 검증했다.
- UI: 재로딩 전 실제 Paseo 다크 화면에서 기본 폰트, 시스템 수치와 단일 메모리 바,
  CPU/메모리 열, 상위 10개 고정 높이 목록, 자동 관리 감시를 확인했다.
  기존 자동 갱신은 mount와 정렬/스크롤을 유지하며 확인 대상은 갱신으로 늘리지 않는다.
  0.2.1 재로딩 후 컴퓨터 제어는 시간 초과됐다. RPC 전달 외 배치 변경은 없다.
- 호환성: 0.10.2 SDK와 DOM 없는 tsconfig를 유지한다. 클라이언트의 DOM/HTML/fontSize 금지 패턴은 0건이다.
  새 라이브러리나 공개되지 않은 종료/호스트 관리 API는 추가하지 않았다.

최종 명령 결과, 바이너리 서명·네이티브 시험, 실제 RPC/수명주기와 부하 수치는
[VALIDATION.md](VALIDATION.md)에 기록한다.

### 당시 남은 실제 검증

- 자연 발생한 임계 압력에서 Paseo 서버 환경의 CLI 실행·전체 자동 흐름은 미검증이다.
  실제 Luna 호출은 0.2.0의 가상 후보로 확인했으며 이번 오류 경계는 가짜 CLI로 검증했다.
- 현재 메모리 합계의 Activity Monitor 화면 대조, 새 자동 관리 화면의 라이트 테마·compact/모바일,
  다른 Mac의 실제 설치는 사용자 확인이 필요하다. 당시 실험 집계는 0.3.0에서 제거했다.
- 비정상적인 데몬 강제 종료/전원 중단은 정상 cleanup을 실행할 수 없다. 상세 로그의 `planned`/`sent`만으로
  프로세스가 종료됐다고 판단하지 않는다. PID 확인과 신호 전송 사이의 경합을 원자적으로 막는 API는 사용하지 않는다.

메모리 압력은 인위적으로 유발하지 않았고 데몬 재시작·전역 설정 변경·다른 Mac 조작은 하지 않았다.
