# agent-graph

현재 워크스페이스의 Paseo 에이전트를 최근순으로 찾아 대화로 이동하는 플러그인입니다. **Paseo 0.10.2 · 플러그인 0.1.11** 기준입니다.

0.1.6부터 최근 목록·검색·대화 이동·ID 복사에 집중합니다. 이전의 그래프·구조 탭·확대 기능과 D3 의존성은 제거했습니다. 기존 설치를 그대로 업데이트할 수 있도록 플러그인 ID는 `agent-graph`로 유지합니다.

## 설치·업데이트

Paseo 0.10.2 데몬에서 플러그인 사용을 활성화한 뒤 설치합니다.

```sh
paseo plugin install github:01-works/paseo-plugin:agent-graph
```

GitHub 설치본의 업데이트는 `paseo plugin update agent-graph`입니다.

로컬 소스를 개발하려면 해당 폴더에서 설치합니다.

```sh
cd agent-graph
npm ci
paseo plugin install "$PWD"
```

설치 후 에이전트 입력창의 **에이전트 N** pill을 누릅니다. N은 현재 워크스페이스의 미보관 에이전트 수입니다. Paseo 설정에서 플러그인이 활성화되어 있어야 합니다.

로컬 설치본은 소스를 업데이트한 뒤 의존성을 설치하고 플러그인만 reload합니다.

```sh
npm ci
paseo plugin reload agent-graph
```

비활성화·복귀는 `paseo plugin disable agent-graph`, `paseo plugin enable agent-graph`입니다. 제거는 `paseo plugin remove agent-graph`입니다.

## 사용

- **최근 목록:** pill을 열면 해당 워크스페이스의 미보관 에이전트만 표시합니다. 각 행에서 이름·상태·시각을 보고, 현재 대화는 왼쪽 표시선과 `현재`로 구분합니다.
- **정렬:** 기본은 활동순입니다. `생성순`을 누르면 새로 만든 에이전트부터 표시합니다. 활동순은 API의 `updatedAt`과 `createdAt` 중 최신 유효 시각을 쓰며, 이름·설정·상태 변경도 포함합니다. 마지막 대화 메시지의 시각과는 다를 수 있습니다. 표시 시각은 기기의 현지 시각입니다.
- **검색:** 이름 또는 ID를 입력합니다. 결과가 하나일 때 Enter로 그 대화를 엽니다. 지우기 버튼으로 전체 목록에 돌아갑니다.
- **대화 이동:** 행을 누르면 해당 에이전트 대화를 엽니다. 이미 열린 대화의 선택·focus는 Paseo의 공개 `navigation.openAgent`가 처리합니다.
- **ID 복사:** 행 오른쪽 복사 아이콘을 누르거나 행을 길게 누릅니다. 대화 이동과 분리된 동작입니다. Paseo 0.10.2에는 공개 우클릭 메뉴 API가 없어 별도 우클릭 메뉴는 제공하지 않습니다.
- **대화 닫기:** 행 오른쪽 ×를 누르고 대상 이름을 확인합니다. 대화를 보관함으로 이동하며, 실행 중인 작업과 연결된 하위 에이전트도 함께 닫힐 수 있습니다. 탭만 숨기는 기능은 아닙니다. 실패하면 목록에서 지우지 않고 확인 창에서 다시 시도할 수 있습니다.

검색·정렬·스크롤은 원래 대화별로 보존합니다. reload·disable·앱 재시작 뒤에는 초기화됩니다. 자동 갱신이 열린 창을 다시 만들지 않으며, 검색 중에도 목록 영역의 높이는 유지합니다. 검색창은 전체 너비를 사용하며, 별도 전체보기 화면은 제공하지 않습니다.

대화 이동을 지원하지 않는 앱에서는 이동 시 오류를 알립니다. pill 목록의 ID 복사는 계속 사용할 수 있습니다. 이동·닫기 직전에 대상의 보관 여부와 워크스페이스를 확인합니다. 에이전트 생성·설정 변경·메시지 전송은 제공하지 않습니다.

검색과 정렬은 테두리·구분선 중심으로 표시합니다. 좁은 화면에서 오늘의 항목은 시간만, 이전 항목은 날짜만 표시하고 전체 시각은 접근성 이름에 유지합니다. 복사·닫기는 각각 44의 누름 영역을 가지며 행 이동과 분리됩니다.

아이콘과 정렬 버튼은 호버할 때 옅은 배경으로 표시합니다. mac-monitor처럼 정렬 라벨 주변의 여백과 모서리를 작게 유지하며, 선택한 정렬은 기본 글자색과 굵기로 구분합니다. 대화 행은 누를 때만 배경을 표시하고, 키보드 포커스는 테두리로 표시합니다. 행 안의 좌우 여백과 아이콘 사이 간격은 유지합니다. 닫기 아이콘은 호버 시 위험 색으로 구분하며, 검색 포커스는 외곽 테두리로 표시합니다. 이 표시 때문에 버튼 크기나 목록 위치가 바뀌지 않습니다.

## 갱신·부하·한계

호스트의 기존 Paseo 연결을 사용하는 client 전용 플러그인입니다. 호스트별 여러 pill·모달이 directory 하나와 owned subscription 하나를 공유합니다. 추가 서버·소켓·헬퍼·CLI 수집을 실행하지 않습니다.

처음에 200개씩 최대 10페이지를 읽고 이후 이벤트를 약 250ms 단위로 묶어 반영합니다. 정상 연결에서 목록을 주기적으로 재조회하지 않습니다. 보이는 뷰가 있을 때만 구독의 로컬 상태를 1초마다 확인하며, 이 확인은 네트워크 요청이 아닙니다. FlatList로 목록을 가상화합니다.

모델 상한은 선택한 호스트 전체의 미보관 에이전트 2,000개입니다. 상한·페이지 실패는 일부 결과로 표시하고, 연결이 끊기면 마지막 목록과 연결 상태를 유지합니다. 오류·부분 결과에서 `다시 읽기`를 사용할 수 있습니다. 복구 중 변경·삭제가 오래된 페이지 응답으로 되돌아가지 않도록 처리합니다.

0.1.6의 실제 로컬 조회는 92개·목록 조회 1회·구독 1개였으며, 이후 5초 동안 추가 조회는 0회였습니다. 2,000개 합성 자료의 활동순 필터·정렬은 Node에서 중앙값 약 **0.50ms**, p95 **0.70ms**였습니다. 이는 순수 처리 비용으로 전체 UI의 CPU·메모리·FPS 측정은 아닙니다. 설치 번들은 0.1.5의 135,323bytes에서 42,806bytes로 줄었습니다.

0.1.7의 실제 설치 번들은 48,899bytes이며 Hermes 컴파일을 통과했습니다. 닫기를 확인할 때만 대상 조회 한 번과 보관 요청 한 번이 추가됩니다. 평소의 구독·조회 방식과 런타임 의존성은 그대로입니다.

0.1.8의 설치 번들은 51,447bytes이며 Hermes 컴파일을 통과했습니다. 호버·포커스는 각 컨트롤의 표시만 갱신하고 네트워크 요청이나 이동·복사·보관을 실행하지 않습니다. 런타임 의존성과 구독 방식도 그대로입니다.

0.1.9는 행의 호버 배경과 글자·아이콘 여백을 보완했습니다. 설치 번들은 51,524bytes이며 Hermes 컴파일을 통과했습니다. 행 높이와 구독 방식은 유지합니다.

0.1.10은 mac-monitor의 정렬 버튼·목록과 비교해 큰 행 호버 배경을 제거하고, 버튼 라벨의 좌우 여백과 모서리를 줄였습니다. 데스크톱 32·compact 44의 누름 영역과 키보드 포커스는 유지합니다. 설치 번들은 51,651bytes이며 Hermes 컴파일을 통과했습니다. 추가 조회나 런타임 의존성은 없습니다.

0.1.11은 전체보기 아이콘·작업 탭·전체 화면 목록·Command Center 항목을 제거했습니다. pill에서 목록·검색·대화 이동·ID 복사·확인 후 닫기를 사용합니다. 검색창은 넓어졌고 공유 구독·가상화·스크롤 보존은 유지합니다. 설치 번들은 48,348bytes이며 Hermes 컴파일을 통과했습니다.

현재 선택한 호스트의 Paseo 등록 에이전트만 표시합니다. 다른 Mac을 합친 목록과 provider 내부에서만 생성된 하위 에이전트는 표시하지 않습니다. 상태는 색과 글자로 함께 보여주며, `결과 확인`을 전체 작업의 성공·완료로 단정하지 않습니다.

실제 Paseo 데스크톱 다크 화면에서 검색·복사·대화 이동과 닫기 확인·취소를 확인했습니다. 0.1.8에서는 Tab 탐색·포커스 표시·Enter로 확인 열기·취소 후 포커스 복귀도 확인했습니다. 0.1.11에서는 전체보기 제거 후 검색창 배치와 기존 대화 탭으로의 이동을 다시 확인했습니다. 사용 중인 대화의 실제 보관은 수행하지 않았습니다. 호버·라이트·다크의 좁은 화면은 RN Web 미리보기, iOS 번들은 Hermes 검사와 호스트 mock 테스트로 확인했습니다. 실제 iPhone의 pill·시트·키보드·길게 누르기·VoiceOver·Dynamic Type과 0.11 이상 호환성은 추가 확인이 필요합니다.

```sh
npm run typecheck
npm test
npm run audit
npm run bench
# 로컬 데몬 목록·구독을 읽기 전용으로 확인

```

7개 파일·58개 테스트, 타입 검사, DOM/HTML·기본 폰트 audit가 통과했습니다. 제품 entry와 실제 설치 번들을 React Native에 포함된 Hermes로 검증했습니다. 상태 정규화·구독 수명·검색·정렬·복사·대화 이동·닫기의 대상 검증·실패/중복 처리·portal 클릭 경계와 호버·포커스의 동작 분리를 확인합니다.
