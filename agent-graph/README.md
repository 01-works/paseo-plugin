# agent-graph

Paseo 에이전트의 부모·자식 구조를 pill에서 열어 보는 플러그인입니다. 부모가 위, 자식이 아래인 그래프와 접이식 목록을 제공합니다. **Paseo 0.10.2**, 플러그인 0.1.0 기준입니다.

## 설치

현재 구현은 로컬 저장소에 있습니다. 이 구현의 GitHub push는 아직 진행하지 않았습니다.

```sh
cd agent-graph
npm ci
paseo plugin install "$PWD"
```

설치 후 에이전트 입력창의 `구조 N · 실행 R` pill을 누릅니다. 100개 이상이거나 compact 화면에서는 `구조 N`으로 줄여 표시합니다.
플러그인 사용은 Paseo 설정에서 활성화되어 있어야 합니다.

수정 반영은 `paseo plugin reload agent-graph`, 비활성화·복귀는 `paseo plugin disable agent-graph`와 `paseo plugin enable agent-graph`입니다.
제거는 `paseo plugin remove agent-graph`입니다. 데몬을 재시작할 필요가 없습니다.

## 사용

- **현재 구조:** 현재 에이전트의 루트와 그 아래 자손을 봅니다. 같은 호스트의 다른 workspace에 있는 자손도 포함합니다.
- **워크스페이스:** 해당 workspace의 에이전트와 자손, 관계를 이해하는 데 필요한 조상을 봅니다.
- **노드 선택:** 아래 카드에 이름·상태·provider/model·workspace·부모·ID를 표시합니다.
- **ID 복사:** 상세 카드의 버튼을 누릅니다. 노드를 길게 눌러도 ID를 복사합니다. 실패하면 오류를 표시합니다.
- **접기·펼치기:** 노드 옆 버튼으로 가지를 접습니다. `+N`은 숨겨진 자손 수입니다.
- **확대:** 75~150%, 25%씩 조절합니다. `맞춤`은 최소 75%까지만 축소합니다. 넓은 구조는 가로·세로로 스크롤합니다.
- **현재 위치:** 현재 대화의 노드를 선택하고 화면 안으로 이동합니다.
- **크게 보기:** 같은 선택·접기·범위를 workspace 작업 패널에서 이어 봅니다. 패널에는 `대화 열기`도 있습니다.
- **목록:** 데스크톱에서도 접이식 목록으로 전환할 수 있습니다. compact는 목록이 기본입니다.

우클릭 메뉴는 Paseo 0.10.2의 공개 플러그인 API에서 제공하지 않아 추가하지 않았습니다.
선택·접기·배율은 플러그인이 켜진 동안 메모리에 유지됩니다. reload·disable·앱 재시작 뒤에는 초기화됩니다.
모달과 패널의 스크롤 위치는 각각 유지합니다. 에이전트를 생성·중단·수정하는 기능은 없습니다.

## 표시 기준

0.10.2의 원시 목록에서 `labels["paseo.parent-agent-id"]`를 읽어 관계를 구성합니다.
부모 필드가 별도로 존재하는 DTO에서는 그 값을 우선하며, 명시적 `null`은 부모 없음입니다.
관계가 없는 에이전트는 독립 루트로 표시합니다. 이름·workspace·프로세스 관계로 부모를 추측하지 않습니다.
Codex·Claude 안에서만 생성되고 Paseo에 등록되지 않은 하위 에이전트는 표시되지 않습니다.

상태는 색과 글자로 함께 표시합니다. 실행 중·시작 중·입력 필요·결과 확인·대기·오류·제공자 사용 불가·닫힘·확인 불가를 구분합니다.
`결과 확인`은 성공이나 전체 작업 완료를 뜻하지 않습니다. pill의 실행 수는 `running`만 포함합니다.
부모가 조회되지 않으면 `부모 정보 없음`, 순환은 문제 연결을 끊고 상세에 표시합니다. 조상 문맥은 실제 에이전트 수에서 제외합니다.

## 갱신과 한계

호스트의 기존 Paseo 연결을 사용하는 client 전용 플러그인입니다. 추가 서버·소켓·헬퍼·CLI 수집을 실행하지 않습니다.
호스트별 인스턴스의 여러 pill·모달·패널이 directory 하나와 owned subscription 하나를 공유합니다.
처음에 200개씩 최대 10페이지를 읽고, 이후에는 이벤트를 약 250ms 단위로 묶어 반영합니다. 정상 연결에서 목록을 주기적으로 재조회하지 않습니다.
보이는 뷰가 있을 때만 구독의 로컬 연결 상태를 1초마다 확인합니다. 이 확인은 네트워크 요청을 보내지 않습니다.

모델은 최대 2,000개입니다. 상한·페이지 실패는 `일부만 표시`로 알리며, 단절 때는 마지막 구조와 `연결 끊김`을 유지합니다.
복구 snapshot을 받으면 페이지를 다시 채웁니다. 오류·부분 결과에서만 `다시 읽기`가 나타납니다.
페이지 조회 도중 도착하는 변경·삭제가 오래된 응답으로 되돌아가지 않도록 처리합니다.

그래프는 최대 2,000개 좌표를 계산하되 화면 주변 노드만 생성하고 한 번에 최대 200개 노드 뷰를 만듭니다.
큰 구조를 축소해 글자를 읽기 어렵게 만들지 않습니다. 매우 넓은 직계 자손은 스크롤·접기 또는 가상화한 목록으로 탐색합니다.
상태·제목 갱신만으로 배치를 다시 계산하거나 창을 다시 만들지 않습니다.

현재는 **선택한 호스트의 Paseo 에이전트**만 표시합니다. 다른 Mac을 합친 fleet 그래프는 제공하지 않습니다.
0.11 이상의 API 호환성, 실제 모바일 터치·라이트 테마는 추가 검증이 필요합니다.

## 검증·개발

```sh
npm run typecheck
npm test
npm run audit
npm run bench
# 실행 중인 로컬 데몬의 목록·구독을 읽기 전용으로 확인
node --import tsx test/manual/live.mjs
```

실제 로컬 목록 296개를 두 번의 페이지 조회와 구독 한 개로 읽고, 이후 5초 동안 반복 조회 0회를 확인했습니다.
2,000개 합성 모델의 정규화 이후 관계·범위·집계·배치 처리 중앙값은 약 2.0~2.7ms였습니다.
이는 Node에서 측정한 순수 데이터 처리 시간이며 전체 Paseo 렌더링 부하나 플러그인의 추가 메모리 사용량을 뜻하지 않습니다.
실제 데스크톱 다크 화면에서 209개 관계, 연결선, 접기·확대·큰 보기·ID 복사·하위 대화 이동을 확인했습니다.
타입 검사·38개 테스트·DOM/기본 폰트 audit와 로컬 disable/enable 검증이 통과했습니다. GitHub workflow는 추가했으며 원격 실행은 아직 하지 않았습니다.

상세 결과는 [VALIDATION](docs/VALIDATION.md), 구현 중 판단은 [DECISIONS](docs/DECISIONS.md)에 기록합니다.
설계와 출처는 [PLAN](docs/PLAN.md), [REFERENCES](docs/REFERENCES.md)에서 볼 수 있습니다.
