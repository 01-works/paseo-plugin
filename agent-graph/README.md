# agent-graph

Paseo가 관리하는 에이전트의 부모·자식 관계를 composer pill에서 열어 보는 플러그인 계획입니다.
현재 에이전트의 구조를 그래프로 살펴보고, 가지를 접거나 확대하고, 큰 작업 패널로 이어서 보는 흐름을 제안합니다.

**현재 상태: 구현 전 계획.** 코드·manifest·설치 가능한 배포는 아직 없습니다.

- [구현 계획](docs/PLAN.md): 화면, 데이터, 0.10.2 API 제약, 구현 순서와 검증 기준
- [레퍼런스 검토](docs/REFERENCES.md): Agent Crew·mac-monitor에서 참고할 점과 그대로 가져오지 않을 점

첫 버전은 Paseo에 등록된 에이전트와 확인 가능한 부모·자식 관계를 보여줍니다.
Codex·Claude 내부에서만 생성된 하위 에이전트, 작업 의존성, 메시지 교환은 표시 대상에 포함하지 않습니다.
