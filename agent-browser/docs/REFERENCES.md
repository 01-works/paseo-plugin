# agent-browser 레퍼런스

구현 기준은 설치된 `@getpaseo/plugin`·`@getpaseo/client` 0.10.2 타입이다. 공개 사이트의 최신 문서는 addScreen 등 이후 API를 포함하므로 0.10.2 구현에 그대로 적용하지 않는다.

- [Paseo 0.10.2 플러그인 API](https://github.com/getpaseo/paseo/blob/v0.10.2/public-docs/plugins/reference.md): composer pill, surface의 공개 navigation, 수명주기와 React Native 요소.
- [Paseo 0.10.2 배포](https://github.com/getpaseo/paseo/blob/v0.10.2/public-docs/plugins/publishing.md): Git 저장소 하위 경로 설치와 manifest build.
- [mac-monitor](../../mac-monitor/README.md): pill·모달과 기본 글자 크기, 작은 정렬 버튼·간격을 참고한 로컬 플러그인.

최초 커뮤니티·그래프 라이브러리 조사는 [이력](history/REFERENCES.md)에 보존한다. 현재 구현은 그래프와 해당 라이브러리를 사용하지 않는다.
