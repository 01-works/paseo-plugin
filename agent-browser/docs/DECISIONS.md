# agent-browser 결정 기록

기준: 0.2.0 · 2026-10-08.

## 이름과 설치

사용자는 이름 변경을 기존 설치 호환 없이 greenfield로 진행하도록 요청했다. 폴더·설치 ID는 `agent-browser`, 패키지는 `paseo-agent-browser`, pill ID는 `browser`로 통일한다. 버전은 이름과 설치 ID가 바뀌는 0.2.0으로 올린다. 이전 이름의 폴더·설치 ID·CI·리다이렉트·호환 wrapper는 제공하지 않는다. 화면 이름은 `에이전트`를 유지한다.

현재 로컬 설치는 새 경로와 ID로 교체한다. GitHub `main` 배포는 앞선 사용자 승인에 따라 계속하며, mac-monitor·데몬·원격 호스트는 변경하거나 재시작하지 않는다.

## 탐색 범위

Paseo 기본 subagent 보기와 중복되는 그래프·전체보기를 제공하지 않는다. 현재 워크스페이스의 최근 목록·이름/ID 검색·대화 이동·ID 복사·확인 후 닫기에 집중한다. 원래 대화별 검색·정렬·스크롤을 메모리에 보존한다.

## API와 수집

SDK·manifest는 Paseo 0.10.2·`>=0.10.2 <0.11.0`을 기준으로 한다. 기존 연결과 구독 하나를 공유하고 정상 상태의 목록 폴링은 추가하지 않는다. 이벤트를 250ms 단위로 묶으며, 로컬 lease 확인은 네트워크 조회가 아니다.

0.10.2 pill에는 navigation이 없으므로 공개 `navigate` surface를 대화 이동에만 사용한다. host/workspace/target을 확인하고 요청당 한 번 이동한다. 별도 목록·라우터·소켓·RPC를 제공하지 않는다.

## 닫기와 UI

닫기는 대상·하위 에이전트 영향 확인 후 공개 refresh/archive API를 사용한다. 성공 뒤에만 목록에서 제거한다. 실제 사용자 대화는 검증 과정에서 보관하지 않는다.

React Native 기본 요소·Paseo의 Modal/FlatList와 theme 색·기본 글자 크기를 사용한다. desktop 32·compact 44의 조작 영역, 현재 대화 표시, 키보드 테두리와 작은 버튼 호버를 유지한다. 이름 변경으로 목록 처리·조회·런타임 의존성은 늘리지 않는다.

이전 설계와 변경 이유는 [이력](history/DECISIONS.md)에 당시 이름·버전 그대로 보존한다. 이력에 등장하는 설치 ID는 현재 지원 경로를 뜻하지 않는다.

## 2026-10-09 · Paseo 0.11.1 호환 (0.2.1)

앱·CLI는 0.11.1, 실행 중인 로컬 데몬은 0.10.2다. SDK를 0.11.1로 올리고 manifest는 `>=0.10.2 <0.12.0`으로 설정한다. 새 `addScreen`·`openScreen`을 우선 사용하며, 해당 메서드가 없는 0.10.2 클라이언트에서는 기존 화면 API로 폴백한다. 새 API의 실패를 구 API로 재시도하지 않아 이동 요청이 중복되지 않게 한다.

구·신 API의 entry 등록부터 실제 대화 이동과 구독 해제까지 자동 테스트로 확인한다. 기존 directory·검색·닫기 흐름은 유지한다. 이 저장소 수정은 기존 로컬 설치 교체나 데몬 재시작을 포함하지 않는다.
