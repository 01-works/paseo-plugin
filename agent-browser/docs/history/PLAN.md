# 이전 에이전트 탐색 계획

0.1.11 당시 계획의 전체 내용은 [보존된 Git 기록](https://github.com/01-works/paseo-plugin/blob/2d691ade47d152cde2521a43e69124745fc2a236/agent-browser/docs/history/PLAN.md)에서 확인합니다.
현재 계획과 대부분 겹치는 본문은 이 파일에 다시 복제하지 않습니다.

당시 폴더·설치 ID는 `agent-graph`, pill ID는 `graph`, SDK는 0.10.2였으며 지원 범위는 `>=0.10.2 <0.11.0`이었습니다.
0.2.0에서 독립된 agent-browser로 바꾸고, 0.2.1에서 SDK 0.11.1과 이전 화면 API의 호환 경로를 적용했습니다.
